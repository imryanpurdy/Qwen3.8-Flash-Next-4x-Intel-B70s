# Documentation index

The recipe repo's documentation, organized by job. The deploy-first entry point is the
[root README](../README.md) — read that first, then come back here for depth.

## Layout

| Path | Contents |
|---|---|
| [`lanes/`](lanes/) | **Specs (source of truth).** `00-shared-context.md` (frozen model identity, box, evidence map), `deploy-kit-contract.md` (deploy kit contract D1–D6 — the single authority the launcher scripts obey), lane 1–6 research specs (graphs quarantine, MTP qualification, block-FP8 GEMM, TTFT sweep, A367 exact-GDN, kernel program) |

| `firstlight-2026-09-16.md`, `rig-skill-snapshot-20260920.md` | Chronological snapshots of rig state |

## Adding a doc

- Rebuild/OS/box work → `rebuild/`; a stall/wedge with captures → `incidents/`; a tuning
  campaign with prereg/results → `campaigns/`; spec-level research → `lanes/`; external
  source material → `evidence/`.
- Date-prefix new narrative docs (`YYYY-MM-DD-<slug>.md`) and add a one-line row here.
- Never invent a number; each doc links its receipts.
